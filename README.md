# Starq Technologies × Cloudroom — Public Contributions

A **public-only** place for Starq Technologies to document **generic, verified, reproducible** issues and improvements for the open-source [Cloudroom](https://github.com/davidondrej/cloudroom) project.

**Special thanks to David Ondrej and the Cloudroom contributors** for openly developing a multi-harness engineering workspace. This is a community contribution channel, **not** a Cloudroom-affiliated or endorsed repository.

## What is welcome

Focused upstream bug reports reproduced on unmodified Cloudroom with **synthetic fixtures**, upstream version/commit references, minimal expected/observed behavior and relevant generic tests. Improvements should go to Cloudroom's own repository via its established contribution process, with links mirrored here only when useful.

## What is not welcome

Internal organizational records, proprietary work items, company/private project names, source paths, customer data, raw logs, tokens, screenshots of confidential UIs, private PR details, security exploit write-ups, or unverified AI-generated issue spam.

## How to contribute

Read [CONTRIBUTING](CONTRIBUTING.md). For vulnerabilities follow [Cloudroom's private security policy](https://github.com/davidondrej/cloudroom/blob/main/.github/SECURITY.md) instead of filing public issues. This repository contains no private Starq OS source or automatic internal issue synchronization.
